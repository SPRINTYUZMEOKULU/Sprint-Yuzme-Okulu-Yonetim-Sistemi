ÖNEMLİ VERCEL AYARI:
Formun Supabase'e kayıt gönderebilmesi için Vercel projesinde şu sunucu değişkeni bulunmalıdır:
SUPABASE_SERVICE_ROLE_KEY = Supabase > Settings > API Keys > Legacy anon, service_role API keys bölümündeki service_role anahtarı

Bu anahtarı kesinlikle NEXT_PUBLIC_ ile başlayan bir adla kaydetmeyin ve kullanıcılarla paylaşmayın.
Mevcut iki değişken de korunmalıdır:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY

Yükleme:
1. ZIP içindeki dosyaları GitHub reposuna topluca yükleyin.
2. Commit oluşturun.
3. Vercel otomatik deploy başlatacaktır.
4. Vercel Environment Variables bölümünde SUPABASE_SERVICE_ROLE_KEY ekleyin.
5. Yeni bir Redeploy yapın.
